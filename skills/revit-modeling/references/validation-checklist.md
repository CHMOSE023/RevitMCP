# 验收清单：每类构件建完要量什么

原则：**回执说"成功"不算数，量回来对得上才算。**
下面每一条都对应一次真实的翻车——那些问题当时全部是"调用成功、警告为 0、几何是错的"。

量的成本不高：`revit_get_element_geometry` 一次可以查一批。
关键实例逐个确认，重复构件按数量与关键参数抽查。

---

## 墙

| 量什么 | 怎么量 | 对不上说明 |
|---|---|---|
| 外轮廓尺寸 | 一圈外墙的包围盒合并，X/Y 尺寸 | 大了一个墙厚 = 定位线绕向反了（外皮定位要**顺时针**给，X 右 Y 上时） |
| 高度 | 包围盒 Z 尺寸 == 两条标高的高差 | 用了 `height` 而不是 `topLevelId`，层高一改就脱节 |
| 厚度 | `revit_list_types` 的 `thicknessMm` | 墙厚由类型决定，创建时改不了——要 200 厚就挑 200 的类型 |

外皮尺寸直接照图给 + `locationLineRef: "FinishFaceExterior"`，**不要**自己把轮廓往里挪半个墙厚。

## 楼板 / 屋顶 / 天花

| 量什么 | 怎么量 | 对不上说明 |
|---|---|---|
| 竖向位置 | 回执的 `elevationMm`，或包围盒 Z | 楼板的偏移参数定的是**顶面**，屋顶是**底面** |
| 洞口 | 面积 == 外轮廓 − 洞口，或查 `OST_FloorOpening` | 2021 及更早的 API 不支持带洞轮廓，洞是事后开的独立构件，按类别查楼板时看不见它 |
| 重叠 | `revit_get_warnings` | 「楼板重叠」**几乎总是位置错了**，不是噪音 |

## 柱

| 量什么 | 怎么量 |
|---|---|
| 底部 | 回执 `baseOffsetMm` / 包围盒 `min.z` == 标高 + 偏移 |
| 顶部 | 包围盒 `max.z` == 顶标高 + `topOffset`；且顶部约束真的绑在标高上（层高变了要跟着变） |

柱**要配 `topLevelId`**，不要靠类型自带的高度。

## 门窗

| 量什么 | 怎么量 | 对不上说明 |
|---|---|---|
| 宿主 | 回执里有宿主墙；平面上墙体真的被开洞 | 没有宿主的门窗看着在、实际没开洞，比失败更坏 |
| 窗台高 | 包围盒 `min.z` == 标高 + `baseOffset` | 族没有窗台高度参数时工具会报错，不会静默用族默认值 |
| 朝向 | `facingDirection`；开启方向 `handDirection` | 门朝里朝外靠 `facingFlipped` / `handFlipped` 翻 |

## 房间

| 量什么 | 期望 | 对不上说明 |
|---|---|---|
| 围合 | `areaSqm > 0`、`isBounded: true` | 为 0 = 墙没接上，用房间分隔线补 |
| 高度 | `unboundedHeightMm` == 层高 | **2438.4 是 Revit 的默认值**（8 英尺），说明没设 `upperLimitLevelId` |
| 体积 | `volumeCbm` | 为 null = 项目没打开「面积和体积计算 → 体积」，不是体积为 0 |
| 重复 | 一个封闭区域只放一个房间 | 「多余的房间」警告说明同一区域放了两个 |

## 视图与图纸

| 量什么 | 怎么量 | 对不上说明 |
|---|---|---|
| 视图类型 | 回执的 `viewType` | 想要立面就得是 `Elevation`，命名成"南立面"的剖面不算 |
| 取景 | 导出图里建筑占多大 | 未收过的视图导出来多半 90% 是白的，先 `revit_set_view_extent` |
| 视口越界 | 回执的 warnings | 中心在纸内不代表整个外框在纸内 |
| 尺寸标注 | 回执的 `value` | Revit 会接受方向不合理的组合并给出无意义读数——量两道竖向轴网要用**水平**尺寸线 |

## 交付前

1. `revit_get_warnings` == 0，或每条都能解释。
2. 关键尺寸抽查一遍包围盒。
3. 导出的图打开看一眼——**看图，不是看导出成功的回执**。
4. `revit_save_document` 先不带 `confirm` 确认要覆盖的是哪个文件。
